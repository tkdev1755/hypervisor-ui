Une modale est une fenêtre posée par-dessus la page. On ne la met jamais dans un .html : on l'ouvre depuis le code avec ModalService.open(), en lui donnant le composant à afficher et ses inputs. open() renvoie une ModalRef, une télécommande. Son afterClosed$ est un Observable qui émet une seule fois, quand la modale se ferme : c'est là qu'on récupère le résultat, puis qu'on recharge la page si besoin. Le premier type entre chevrons (ConfirmModalComponent) permet à TypeScript de vérifier les inputs : une faute de frappe sur un nom, ou un nombre à la place d'un texte, ne compile pas. Le second (boolean) est le type du résultat. On écrit action: () => this.vms.delete(id), avec la flèche. Sans elle, la requête partirait à l'ouverture de la modale, avant même que l'utilisateur ait confirmé. Lancez la confirmation, puis fermez-la de trois façons (Annuler, la croix, Échap) et regardez le résultat. Essayez aussi de fermer la modale pendant le chargement : c'est impossible.
