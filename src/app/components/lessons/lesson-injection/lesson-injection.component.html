L'injection, version avancée. Jusqu'ici, inject(MonService) recevait une classe. Pour fournir autre chose (une liste, une valeur, une configuration), on crée un jeton : new InjectionToken<T>('NOM'). Avec multi: true, chaque fournisseur ajoute un élément à une liste au lieu de remplacer le précédent. C'est le modèle de deux briques du projet : un mapper d'erreurs par API, et un descripteur par type de donnée du ContextBridge. Pour ajouter une API ou un type, on ajoute une ligne dans app.config.ts ; le code existant ne change pas. Les génériques. K extends ContextType signifie « K est l'un de ces types ». Le reste de la signature en dépend : le type de value se déduit du premier argument. L'éditeur refuse une donnée qui ne correspond pas, avant même de lancer l'application. keyof produit l'union des noms de champs d'une interface. On n'écrit jamais l'objet {{ objetFournisseur }} à la main dans app.config.ts : la fonction provideXxx le fait, et l'oubli de multi: true (qui écraserait les autres) devient impossible. Dans lesson-injection.component.ts, écrivez bridge.prime('hypervisor', 'x', 42) : l'éditeur souligne l'erreur en rouge.
