Une modale est un composant comme les autres, avec trois particularités : • elle injecte ModalRef pour se fermer elle-même (modalRef.close(resultat)) ;
• elle enveloppe son contenu dans <app-modal-shell>, qui fournit le titre, la croix, et les écrans de chargement, de succès et d'erreur ;
• elle garde son état dans un signal state qui prend, dans l'ordre, les valeurs 'form', 'loading', puis 'success' ou 'error'. Le cadre affiche ce qui est écrit entre ses balises uniquement dans l'état « form ». Le mot footer sur un élément le place en bas, à côté des boutons : c'est la projection de contenu (ng-content select), la même mécanique que demo dans les leçons. Pendant l'état « loading », le cadre bloque la fermeture (croix, Échap, clic à côté) en écrivant dans modalRef.closeGuard : une action en cours ne peut pas être abandonnée par erreur. C'est le rôle du signal submitted : sans lui, le champ serait rouge dès l'ouverture, avant même que l'utilisateur ait tapé quoi que ce soit. Validez avec un champ vide (erreur de saisie), puis avec « db-01 » (erreur de l'API, puis « Réessayer »), puis avec un nom valide (succès, puis « Terminer »).
