Trois écritures suffisent pour relier le HTML à la classe : • {{ accolades }} affiche une valeur ;
• (pressed)="methode()" appelle une méthode quand on clique ;
• [propriete]="valeur" passe une valeur à un composant. Un signal contient une valeur qui peut changer. Quand elle change, Angular met à jour l'écran tout seul. On le lit en l'appelant avec des parenthèses (compteur()), et on le modifie avec set ou update. Un computed est une valeur calculée à partir d'autres signals. Écrire compteur au lieu de compteur() : sans les parenthèses, on n'obtient pas la valeur. Compteur : {{ compteur() }} Double : {{ double() }} +1 Remettre à zéro
