Dans ce projet, on n'écrit ni balises HTML classiques ni CSS : on assemble des composants de mise en page, comme en Flutter. Une <app-row> place ses enfants côte à côte, une <app-column> les empile, et l'on règle les espaces avec [gap] (en pixels). Avant d'écrire un écran, dessinez-le en boîtes : quelles boîtes sont côte à côte (Row), lesquelles sont empilées (Column) ? Le code suit directement ce dessin.
