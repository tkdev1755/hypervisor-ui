Un service est une classe partagée par toute l'application. Chez nous, chaque service regroupe les appels d'une partie de l'API (dossier services/). Un composant obtient un service en écrivant inject(HypervisorService) : c'est l'injection. Un appel HTTP prend du temps : il renvoie un Observable, une réponse qui arrivera plus tard. Avec .subscribe(), on dit quoi faire quand elle arrive (next) ou si elle échoue (error). Tant que personne n'appelle .subscribe(), la requête ne part pas. Cliquez avec l'API arrêtée, puis démarrée (npm run mock) : vous verrez les deux cas. Appeler GET /ping @if (reponse(); as reponse) { Réponse : status = "{{ reponse.status }}", content = "{{ reponse.content }}" } @if (erreur(); as erreur) { }
