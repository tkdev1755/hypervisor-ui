Une variable est une boîte qui porte un nom et contient une valeur. On la crée avec let si sa valeur peut changer, ou avec const si elle ne changera plus. TypeScript, c'est du JavaScript avec des types : on précise ce que contient chaque variable. Les trois types de base sont string (du texte, entre apostrophes), number (un nombre) et boolean (vrai ou faux : true / false). TypeScript vérifie le code avant même de le lancer : si vous mettez du texte là où un nombre est attendu, l'erreur est soulignée en rouge dans l'éditeur.
