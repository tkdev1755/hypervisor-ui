Un écran Angular est un assemblage de composants : des morceaux d'interface réutilisables. Chaque composant tient dans un dossier de trois fichiers : • .ts : la classe, avec les données et les actions ;
• .html : ce qui s'affiche ;
• .scss : l'apparence (chez nous, presque toujours vide). Le décorateur @Component relie les trois. Son selector est la balise qui affiche le composant, et sa liste imports déclare les autres composants utilisés dans son HTML. La commande npx ng generate component components/mon-composant crée le dossier et les trois fichiers d'un coup.
