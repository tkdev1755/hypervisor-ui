Un objet regroupe plusieurs valeurs sous des noms : une VM a un nom, une mémoire, un état. Une interface décrit la forme que doit avoir cet objet : TypeScript refusera un objet auquel il manque un champ. Un tableau est une liste de valeurs, entre crochets. On s'en sert tout le temps avec trois outils : filter (garder certains éléments), map (transformer chacun) et reduce (tout combiner en une seule valeur).
