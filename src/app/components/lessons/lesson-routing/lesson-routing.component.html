Le routeur associe une adresse à une page. Une partie d'adresse précédée de deux-points (:id) est un paramètre : /hypervisors/abc-123 appelle la même page que /hypervisors/xyz-789, avec un id différent. Grâce à withComponentInputBinding(), ce paramètre arrive directement dans un input() de la page, sans rien à lire à la main. Il suffit de donner à l'input le même nom que le paramètre. Avec loadComponent, Angular ne télécharge le code d'une page que lorsqu'on la visite pour la première fois : l'application démarre plus vite. Dans le terminal, ng build liste d'ailleurs ces morceaux (« lazy chunks »). L'URL ne peut pas contenir un objet, seulement des chaînes, et l'utilisateur peut la modifier. On n'y met donc qu'un identifiant ; le reste des données est retrouvé à partir de lui. C'est exactement le rôle de la leçon 14 (le ContextBridge). Ouvrez un hyperviseur depuis la liste, puis rafraîchissez la page (F5). L'adresse ne contient que l'identifiant, et pourtant la page se réaffiche : la donnée a été rechargée depuis l'API.
